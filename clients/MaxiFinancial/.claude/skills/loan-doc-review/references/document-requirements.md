# Document requirements by scenario

Standard Australian home-loan supporting-document requirements, built from common lender and NCCP /
responsible-lending expectations. Requirements vary between lenders — treat these as the baseline a
careful broker would assemble, and flag genuinely lender-specific items as 🟠 Review rather than hard
failures.

Assemble a file's checklist as: **Base (everyone)** + **Income-type add-on** + **Loan-purpose add-on**.

## Freshness windows
A document that's present but older than its window is not a clean pass — mark it ⚠️ Stale (usually
🟠 Review). Common expectations:

| Document | Typical freshness | Notes |
|---|---|---|
| Payslips | Most recent within ~30 days | Need the 2 (or more) most recent, consecutive |
| Transaction / savings statements | Cover the most recent ~90 days, continuous | Used for living-expense verification & genuine savings |
| Credit card / liability statements | Most recent cycle | Must show the credit limit, not just balance |
| PAYG income statement / NOA | Most recent financial year | |
| Tax returns & financials (self-employed) | Last 2 financial years | Most recent year not more than ~18 months old |
| BAS | Last 4 quarters | |
| Rental appraisal / estimate | Within ~90 days | For investment income |
| Contract of Sale | Current / unexpired | |
| Rates notice | Current year | |

## Base requirements (all files)
Required regardless of scenario:

- **Photo identity — primary:** current driver licence OR passport (a full VOI is typically 100 points;
  a primary photo ID plus a secondary is the common minimum). Check name, DOB and photo are legible.
- **Secondary ID:** Medicare card, or birth certificate, or another government document — to complete
  identity verification.
- **Living-expenses evidence:** transaction/bank statements covering ~90 days so declared living
  expenses can be verified against actual spending (not just a declared figure). This is a
  responsible-lending essential.
- **Liabilities documentation:** statements for every existing debt — home loans, personal/car loans,
  credit/store cards (showing limits), BNPL, HECS/HELP where relevant. Undisclosed or undocumented
  liabilities are a common lender query.
- **Consent / authority:** privacy consent and credit-check authority on file (the signed
  application / fact-find usually covers this). Flag if absent.

## Income add-on: PAYG
For each PAYG applicant:

- **2 most recent payslips**, consecutive, most recent within ~30 days, showing YTD figure, employer
  name and pay frequency.
- **Income confirmation:** most recent PAYG payment summary / income statement OR most recent tax
  return + Notice of Assessment.
- **Salary credits visible** in the transaction statements (already collected in Base) — used to
  reconcile against the payslip.
- **Where income includes overtime / bonus / commission / allowances:** stronger evidence (often 2
  payslips + prior-year summary, sometimes an employer letter) since lenders shade this income.
- **Recently started a job / probation:** employment contract or letter confirming ongoing permanent
  role — flag if the payslip suggests a short tenure and no contract is present.

## Income add-on: Self-employed
For each self-employed applicant:

- **2 years personal tax returns** + matching **Notices of Assessment** (the NOA confirms the return
  was lodged and assessed — a return without an NOA is weak evidence).
- **2 years business financials:** business tax returns + profit & loss and balance sheet (for
  company/trust/partnership structures).
- **BAS** for the last 4 quarters (supports recent trading, especially if the latest financials are
  aging).
- **ABN / GST registration** consistent with the trading period claimed.
- **(Low-doc / alt-doc only):** accountant's declaration and/or business bank statements in place of
  full financials — flag clearly if the file looks like a low-doc structure, as it carries different
  requirements and pricing.

## Purpose add-on: Owner-occupier purchase
- **Contract of Sale** (signed) for the property being purchased.
- **Evidence of deposit / genuine savings:** ~3 months of savings history showing funds accumulated
  (the "5% genuine savings" expectation for higher-LVR loans). A lump sum with no history needs
  explanation.
- **Gift letter** (statutory declaration) if any part of the deposit is gifted.
- **First Home Owner Grant / stamp-duty concession** application and eligibility evidence, if a
  first-home buyer.
- **Evidence of funds to complete** (deposit paid receipt, savings covering the balance + costs).

## Purpose add-on: Investment purchase
Everything in Owner-occupier purchase, plus:
- **Rental estimate / appraisal** for the subject property (letting agent letter), current within
  ~90 days — supports the projected rental income.
- **Existing rental evidence** if the borrower already owns investment property: current lease
  agreement(s) and recent rental statements.
- **Evidence of existing property outgoings** (rates, strata/body corporate, landlord insurance)
  where they affect serviceability.

## Purpose add-on: Refinance
- **Current mortgage statement(s)** for the loan(s) being refinanced — showing balance, limit, rate
  and account details.
- **6 months' repayment history / conduct** on the existing loan(s) — lenders assess arrears and
  conduct; this is a core refinance document.
- **Payout / discharge figure** or enough detail to estimate it.
- **Rates notice** for the security property (confirms ownership and property details).
- **Reason for refinance** consistent with the file (cash-out, rate, debt consolidation) — for
  cash-out or debt consolidation, evidence of the purpose/debts being consolidated supports BID.

## Purpose add-on: Construction
- **Fixed-price building contract** (signed) with the builder.
- **Council-approved plans and permits** (or evidence they're in train).
- **Builder's details:** licence/registration and builder's insurance / home warranty insurance.
- **Progress-payment (drawdown) schedule.**
- **Quotes for out-of-contract items** (e.g. landscaping, driveways) if included in the loan amount.
- **Land contract** if land and build are being financed together.
