# MOSIC social topics

The weekly scheduled task takes the first unticked row in Queue dated this week or earlier and makes the post with the `mosic-carousel` skill.

Row format: `- [ ] YYYY-MM-DD | topic (plus any angle or notes) | carousel / single / blank`
- Date = the week you want it posted (the task picks it up from that date on).
- Format blank = the skill chooses.
- Add notes in the topic text if you want a specific angle, e.g. "runner's knee — aimed at people who ran the marathon".
