# Build a photographer portfolio website Build a clean, elegant, fully responsive photography portfolio website as a static site using plain HTML, CSS, and vanilla JavaScript (no framework, no build step — it should run by opening index.html or via a simple local server). Organize files sensibly: /index.html, /portfolio.html, /about.html, /contact.html, /services.html, plus /css/ and /js/ folders, and an /images/ folder. Keep the aesthetic minimal, editorial, and photo-forward: lots of white space, a refined serif for headings, a clean sans-serif for body text, neutral palette (off-white background, soft black text, one understated accent). ## Images All photos for the site are already in the local project folder. Scan the folder for image files (.jpg/.jpeg/.png/.webp), move/copy them into /images/ if they aren't already there, and use the real files throughout — do NOT use external placeholder URLs or lorem-pixel services. If there aren't enough images for a section, reuse what's available rather than linking to remote placeholders. ## Global: left navigation menu (signature element) Every page has a fixed vertical navigation menu pinned to the LEFT edge of the viewport. It behaves like a slide-out "Explore" panel: - A small "Explore" / menu toggle is always visible top-left. - Clicking it slides open a left-side panel listing the page links stacked vertically, with a "Close" control. - The nav links, in THIS exact order: Home, Portfolio, About, Contact. (Do NOT include a Blog link.) - Style the links large and elegant with a subtle hover underline/fade. - On mobile the same left panel works as the primary menu. ## Home page (index.html) 1. HERO — "scattered" photo mosaic. Fill the hero area with many image thumbnails of VARYING sizes arranged in an irregular, organic, scattered layout — slight random rotations and offsets, some overlap, like photos tossed across a table (use absolute positioning or a masonry-style irregular grid; add gentle on-hover scale/lift). It should feel densely scattered, not a tidy uniform grid. Make it responsive — collapse gracefully on mobile. Overlay a short tagline. 2. INTRO — a brief one-paragraph studio intro under the hero. 3. "FIND OUT MORE" — a small row of links to About and Services. 4. KIND WORDS — a testimonials section (see below). ## Kind Words section A dedicated testimonials section titled "Kind Words". Include 5–7 testimonial blocks; each block has: a client name (e.g. "Kate & Nick"), a 2–4 sentence warm quote praising the photography, and an accompanying photo. Stack them vertically with generous spacing, alternating image left/right for rhythm. Write the testimonial copy yourself as realistic filler. ## Other pages — generate realistic filler content for each - **Portfolio (portfolio.html):** A gallery grid of the available images. Optionally group into a few named "sets" with short captions. Clicking an image opens a simple lightbox. - **About (about.html):** A photo plus 2–3 paragraphs of warm, first-person filler bio copy about the photographer's style and approach, a short list of values/approach, and a closing call-to-action linking to Contact. - **Services (services.html):** 2–3 packages/offerings as cards (name, short description, what's included, a "from $X" style price as filler) plus a short intro paragraph and a CTA to Contact. Link to this page from the home "find out more" row. - **Contact (contact.html):** Filler intro line, a contact form (name, email, message — front-end only, no backend; on submit just show a thank-you message), and placeholder contact details (email, location, social links). ## Technical requirements - Fully responsive (mobile, tablet, desktop). - Semantic HTML, accessible (alt text on images, keyboard-operable nav/lightbox). - Smooth, subtle transitions; nothing flashy. - Shared CSS and the left-nav JS reused across all pages (no duplication). - Comment the code lightly so I can edit copy and swap images easily. Start by listing the image files you find in the folder and proposing the file structure, then build it.
