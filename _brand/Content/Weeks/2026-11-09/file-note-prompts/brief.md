## Slide copy

1. **Cover**
   - Hook: 4 prompts for cleaner file **notes**
   - Subline: Copy them. A person still signs off.
2. **Why it matters**
   - File notes written at the end of the day, from memory, miss things.
   - These turn rough notes into a draft you **check**, not a blank page.
3. **1 Draft from rough notes** (use straight after the meeting)
   - Prompt card:
     > Turn these rough meeting notes into a file note with these headings: Client, Date, Purpose of meeting, What was discussed, What the client asked for, Actions and who owns them. Use only what's in the notes. If something is missing, write [check] instead of guessing. Notes: [paste]
4. **2 Find the gaps** (use before you save it)
   - Prompt card:
     > Read this draft file note. List anything a reviewer would expect to see that isn't there, like dates, who attended, what the client was told and next steps. Don't add it yourself. Just list it.
5. **3 Confirm it with the client** (use the same day)
   - Prompt card:
     > From this file note, write a short email to the client confirming what we discussed and what happens next. Plain English, no jargon, no advice or recommendations, under 120 words.
6. **4 Pull out the actions** (use at the weekly catch-up)
   - Prompt card:
     > Pull every action out of this file note. For each one, give what it is, who owns it, and the due date if one was mentioned. Put it in a table.
7. **Before you paste**
   - Checklist (blue ticks): Strip names, TFNs and account numbers, or use your firm's business AI account / A person reads every draft before it's saved or sent / Keep the final file note in your own system, not the chat
   - Line: AI drafts. Your team **decides**.
8. **CTA**
   - Line: Save this for your next team **meeting**.
   - Orange button: Save this
   - Small line: New AI fix every Thursday. @locatingsam
