# Trend log — what's spiking week by week

5-minute weekly pulse. The `reels-script` skill reads this for current-week patterns to tilt scripts toward what's hot.

## Entry template

```
## Week of [YYYY-MM-DD]

**Hooks spiking**
- [pattern + 1 example]

**Formats spiking**
- [e.g. text-on-black with green-screen overlay; POV split-screen]

**Audio seen 2+ times in my niche**
- [audio name + original creator if known]

**One pattern to test this week**
- [the single thing I'll try]

**Notes**
- [anything else worth remembering]
```

## How to fill it
- Every Monday, scroll your saved/explore feed for 5 mins
- Look for repetition — if you see the same hook structure or audio twice in your niche, log it
- Don't chase generic IG trends; only log what hits in service-business / agency adjacent content
