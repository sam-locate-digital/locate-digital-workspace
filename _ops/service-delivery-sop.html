Service playbook

Each: what's delivered, the steps, "done when", and the skill. skill exists · gap use the .claude/ads-* library or the steps here.

1. Onboarding + setup client-onboarding

Full client workspace, account access, kickoff call, month-one plan. Run the onboarding skill, connect Google Ads / Meta / GA4 / GTM / website / GBP, record the baseline (current leads/month) in CLAUDE.md, agree reporting date + contact. Done when every account is connected and the baseline is recorded. Once-off — covered by the $1,500 setup fee.

2. Account audit .claude/ads-audit

A short ranked findings doc — what's wrong, what it costs, what we fix first. Pull the ad account, GA4, GBP; note wasted spend, missing tracking, off-catchment clicks; rank by impact. Done when the client has a plain-English ranked fix list. Once-off at setup, then quarterly.

3. Conversion tracking tracking-setup

Every lead action tied back to the ad. Starter = GA4 events; Growth = GA4+GTM + pixels; Scale = server-side/CAPI. Test every event before launch. Done when a test lead appears correctly in GA4 and the ad platform. Once-off; recheck quarterly. Hard gate — no campaign launches on broken tracking.

4. Google Ads google-ads-copy

Built + managed search/display campaigns on their catchment. Keyword research, structure + targeting, RSA copy, then monthly optimisation (search terms, negatives, bids, budget). Done when live, tracking conversions, reviewed monthly. Deeper analysis: .claude/ads-google.

5. Meta Ads meta-ad-copy

Built + managed Facebook/Instagram campaigns. Set objective + audiences + placements, produce creative, watch frequency/fatigue, refresh on cycle. Done when live, tracked, creative refreshed before fatigue. Deeper: .claude/ads-meta.

6. Extra platform — YouTube / LinkedIn (Scale) .claude/ads-youtube · ads-linkedin

A third channel matched to the client. Mirror the paid-media build — objective, audience, creative, tracking, optimise. Done when live and pulling weight in the report.

7. Audience targeting + segmentation in ad-copy skills

Spend pointed at the right people in the right area. Define catchment + demographics + intent; Growth+ split audiences; Scale add retargeting. Done when no budget goes to out-of-area/irrelevant audiences. Set at build, review monthly.

8. Ad creative + copy google-ads-copy · meta-ad-copy · humanizer

The headlines, descriptions, images, video. Write to offer + audience, produce test variations, keep on-brand and in plain Australian English. Done when each campaign has enough variations to test. Refresh monthly.

9. A/B testing (Growth + Scale) .claude/ads-test

Structured tests that tell you what works. One variable at a time, set a hypothesis + sample size, run to significance. Done when significant and the winner is rolled out. Ongoing.

10. CRO (Scale) landing-page

More of existing traffic converting. Find the drop-off, fix the page, test the change. Done when conversion rate improves and holds. Ongoing. Reference .claude/ads-landing.

11. Landing pages landing-page

Purpose-built page matched to the ad. Write with the skill, match message to ad, one clear CTA, mobile-first. Done when live, tracked, message matches the ad. Per campaign / add-on.

12. SEO — on-page, technical, keywords, meta seo-audit

Pages that rank for local "near me" search. Run the audit, keyword research for service+suburb, fix titles/meta/headings/internal links. Growth up to 5 pages, Scale up to 10. Done when target pages optimised and red flags cleared. Audit once, implement, recheck quarterly.

13. Blog + Google Business content mosic-blog-post · mosic-gmb-post

SEO-friendly posts, written and published. Topics from keyword gaps + patient questions, write in client voice, run through humanizer, publish + internally link. Done when live, on-brand, reads human. Growth 1/mo, Scale 2/mo.

14. Link building (Scale) none yet

Quality local + industry backlinks. Local directories/associations, partner sites, digital PR; track new links + domain authority. Done when new relevant links earned and logged. Ongoing.

15. Email marketing (add-on) email-campaign

Full campaign/sequence — every email, design, automation, segmentation. Run the skill, set segments + triggers, A/B subject lines. Done when built, segmented, scheduled. Monthly (1–3 campaigns by package).

16. Monthly report + call monthly-report-narrative

Plain-English report (leads, cost per lead, what changed, what's next) + the call. Pull numbers, run the narrative skill, hold the call (Starter monthly, Scale fortnightly). Done when the client understands results + next month's plan. Monthly.

17. Strategy consulting (add-on, $200/hr) no skill — billed expertise

Bespoke advice — planning, market entry, channel strategy. Scope, think, hand over clear recommendations. Done when the client has a decision to act on. As booked.

Skill gaps worth filling

No dedicated Locate skill yet — currently leaning on the .claude/ads-* library or manual steps:

  1. ad-audit — standardise setup + quarterly audit
  2. link-building — Scale only, lowest volume

Conversion tracking → tracking-setup (built). Blog + Google Business → mosic-blog-post / mosic-gmb-post. A/B testing + CRO covered well enough by the .claude library.

The one rule: nothing goes live on broken tracking. If you can't measure the lead, you can't prove the result — and the result is the whole product.
