Most broker file notes get written at the end of the day, from memory.

That's the wrong time to be recording why a loan was recommended.

It's usually the first workflow I set up with a firm. After the meeting, the broker drops in their rough notes or the call transcript. Claude drafts the file note in the firm's own template: the client's objectives, what was discussed, the options considered, and why the recommendation fits.

The broker reads it, fixes anything that's off and signs it off. Nothing goes on file without them.

It runs in the firm's own workspace, not a free account someone signed up for.

The note gets written while the meeting is still fresh, and the end of the day goes back to clients.
